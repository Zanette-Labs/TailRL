# Code-optimization experiment, on top of the repo root's requirements.txt.
#
# Install torch FIRST, matched to your CUDA runtime, then this file. vLLM and
# flash-attn build against your torch/CUDA, so letting pip resolve torch as a
# transitive dependency of vllm is how you end up with a torch that does not match
# your driver:
#
#   pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu124
#   pip install -r requirements.txt
#
# Pin deliberately: this experiment runs RL through the vendored verl fork in ./verl,
# whose worker and rollout plumbing tracks specific vllm/transformers/tensordict
# releases.
#
# NOTE: this is the TRAINING environment. The gem5 simulator needs its own, separate,
# python 3.8 environment, which scripts/setup_gem5.sh creates for you. The two never
# interact -- gem5 is only ever run as a subprocess.
